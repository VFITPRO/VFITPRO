# Buddy English 🤖

App web para practicar conversación en inglés hablando con un robotcito.

- Escenarios: restaurante, gimnasio, aeropuerto, entrevista, charla libre
- Niveles A1–C2 (cambia la velocidad de la voz)
- Micrófono (Safari/Chrome), voz del robot y modo escrito como alternativa
- Funciona sin servidor ni claves: un solo archivo `index.html`

URL pública (tras publicar en GitHub Pages): `/buddy-english/`
